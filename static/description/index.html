AUTO-INFO : Membership Report Context Fix

Fixes invalid date-domain context values in Odoo 15 Members Analysis without touching core files.

Important: Install this module only after placing it under /var/odoo/custom15_autoinfo and confirming that the target database uses the membership module. Installing into the wrong database or with an incorrect addons path can prevent the server from loading the expected module set.

What this module does

  • Removes unsafe default context values that can produce ('start_date', '=', 1).
  • Stores the original window action context before applying the fix.
  • Restores the original context when the module is disabled or uninstalled.
  • Adds an admin toggle in Settings for temporary deactivation.

Deployment path

/var/odoo/custom15_autoinfo/autoinfo_membership_report_context_fix
